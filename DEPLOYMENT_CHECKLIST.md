## Deployment Steps 📋

### 1. Push to GitHub
```bash
git add .
git commit -m "Configure for Railway deployment"
git push origin master
```

### 2. Railway Setup
- [ ] Create Railway account
- [ ] Create new project from GitHub
- [ ] Add PostgreSQL database
- [ ] Set environment variables:
  - SECRET_KEY
  - DEBUG=False

### 3. Post-Deployment
- [ ] Wait for build to complete

## Environment Variables Required 🔐

### Railway Dashboard → Settings → Variables

```
SECRET_KEY=<generate-new-secret-key>
DEBUG=False
```

### Auto-Generated by Railway
```
DATABASE_URL=<postgresql-connection-string>
RAILWAY_PUBLIC_DOMAIN=<your-app>.up.railway.app
PORT=<assigned-port>
```

## Generate SECRET_KEY

Run this command locally:
```bash
python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
```

Copy the output and use it as your SECRET_KEY in Railway.

## Create Admin User

After deployment, in Railway terminal:
```bash
python manage.py create_admin
```

Default credentials:
- Username: `admin`
- Password: `admin123`

**⚠️ IMPORTANT: Change this password immediately!**

## Common Issues & Solutions 🔧

### Build Fails
- Check requirements.txt syntax
- Verify Python version in runtime.txt
- Check Railway build logs

### Static Files Not Loading
- Verify collectstatic ran in logs
- Check WhiteNoise configuration
- Ensure STATIC_ROOT is set

### Database Connection Error
- Verify PostgreSQL is added
- Check DATABASE_URL is set
- Ensure migrations ran

### Media Files Missing
- Check copy_media_to_static ran
- Verify media files are in Git
- Check staticfiles/media/ exists

## Updates 🔄

To update your deployed app:
```bash
git add .
git commit -m "Update description"
git push origin master
```

Railway will automatically redeploy.

## Rollback 🔙

If something goes wrong:
1. Go to Railway dashboard
2. Click on your service
3. Go to "Deployments" tab
4. Click on a previous successful deployment
5. Click "Redeploy"
